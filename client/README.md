# Frontend

This folder contains the React, Vite, and Tailwind CSS dashboard.

From this folder, install dependencies and start the development server:

```powershell
npm install
npm run dev
```

Run `npm run build` to create a production build and `npm run lint` to check
the frontend code. The Songs page uses the backend at
`http://localhost:5000/api/songs`; see the [project README](../README.md) for
instructions to run both applications.
